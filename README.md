# 🏫 EVSU Reserve – Smart Facility Booking System

A web-based facility reservation and management system built with **Django**, designed for schools and organizations to efficiently manage room, event, and equipment bookings.

---

## 🚀 Features

### 👤 User Side
- User registration and login
- Facility browsing and reservation
- Real-time booking status updates (pending, approved, rejected)
- Equipment reservation per booking
- Notification system (approval, rejection, updates)
- Booking history and details view

### 🧑‍💼 Admin Side
- Admin dashboard with analytics
- Manage reservations (approve / reject)
- View booking details
- Manage users
- Facility and equipment management
- Notification system for new bookings and registrations

### 🔔 Notification System
- Real-time notifications (AJAX-based)
- Clickable notifications:
  - Reservation → Booking detail page
  - New user → Admin users page
- Mark as read / unread system
- Badge counter for unread notifications

### 📅 Calendar System
- Monthly calendar view
- Shows reservations per day
- Event indicators (dot system)
- Click day → view reservations
- Sidebar upcoming reservations with filters

---

## 🛠️ Tech Stack

- **Backend:** Django (Python)
- **Frontend:** HTML, Tailwind CSS, JavaScript
- **Database:** SQLite / MySQL (configurable)
- **UI Icons:** Material Icons
- **AJAX:** Fetch API (for notifications & updates)
